# 📱 PANDUAN NAVIGASI MOBILE - PPDB SYSTEM

## ✨ FITUR BARU

### 🎯 Dua Cara Akses Menu:

#### 1️⃣ **SIDEBAR MENU** (Menu Lengkap)
- **Lokasi:** Tombol `☰ Menu` di kiri atas (warna biru)
- **Cara Buka:** 
  - Tap tombol `☰ Menu`
  - Sidebar akan slide dari kiri
  - Tap area gelap (overlay) untuk tutup
  - Atau tap menu untuk auto-close
- **Kegunaan:** Akses semua menu lengkap dengan submenu

#### 2️⃣ **QUICK MENU** (Menu Cepat)
- **Lokasi:** Tombol `⊞ Menu Cepat` di kanan atas (warna hijau)
- **Cara Buka:**
  - Tap tombol `⊞ Menu Cepat`
  - Dropdown muncul dari atas
  - Pilih menu yang diinginkan
- **Kegunaan:** Akses cepat tanpa buka sidebar

## 🔧 TROUBLESHOOTING

### Sidebar tidak muncul?
1. ✅ Refresh halaman (Ctrl + F5)
2. ✅ Cek apakah JavaScript error di Console (F12)
3. ✅ Pastikan lebar layar < 768px

### Menu tidak auto-close?
1. ✅ Tap area overlay (area gelap)
2. ✅ Tap tombol ☰ lagi
3. ✅ Swipe sidebar ke kiri

### Table tidak bisa scroll?
1. ✅ Geser/swipe table ke kiri/kanan
2. ✅ Perhatikan indicator "← Geser untuk melihat →"
